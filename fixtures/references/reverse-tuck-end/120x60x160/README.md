# Reverse Tuck End Reference Fixture

Place one trusted reference file for the 120 x 60 x 160 mm Reverse Tuck End carton in this folder.

Accepted manual fixture formats:

- `reference.svg`
- `reference.pdf`
- `reference.png`

Preferred format for automated geometry comparison:

- SVG with layer hints such as `data-layer="cut"` and `data-layer="crease"`, or class/id names containing `cut` and `crease`.

Record the source and license/usage notes in `manifest.json` before using the fixture to promote verification status.
